# Sueca reference adaptation

Typography and button geometry inspected at https://sueca-skf.vercel.app/styles.css.

- SKF Sans Regular: https://fonts.skf.com/SKFSans-Regular.woff2
- SKF Sans Medium: https://fonts.skf.com/SKFSans-Medium.woff2
- SKF Sans Bold: https://fonts.skf.com/SKFSans-Bold.woff2
- SKF Display Bold: https://fonts.skf.com/SKFDisplay-Bold.woff2
- Industrial background: https://sueca-skf.vercel.app/assets/application-industrial.jpg
- Brand icons: Simple Icons v15, https://cdn.jsdelivr.net/npm/simple-icons@v15/icons/whatsapp.svg and https://cdn.jsdelivr.net/npm/simple-icons@v15/icons/instagram.svg

The visible headings and body use SKF Sans as in the Sueca reference. Button shape uses 4px corners, 12px/18px padding and 200ms hover feedback, retaining AlphaRol blue. Fonts and images are stored locally for rendering without runtime dependency on the reference site.
